# Study Quiz App

A simple Flask study app that lets users create quiz questions and test themselves.

## Features

* Add quiz questions
* Take quizzes
* Check answers
* Delete questions

## Tech Stack

* Python
* Flask
* pytest

## Run Locally

```bash
python app.py
```

Then open:

```text
http://127.0.0.1:5000
```
