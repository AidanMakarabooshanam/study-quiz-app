# CLAUDE.md

## Project Overview

This project is a simple Flask study quiz app. Users can create quiz questions, answer them, and practice studying through a lightweight web app. The goal is to keep the project small, easy to understand, and fully functional.

## Tech Stack

The project uses Python and Flask because they are simple, beginner-friendly, and work well for small web applications. Testing will use pytest.

## Coding Conventions

* Prefer small focused functions
* Use clear variable names
* Keep data in-memory instead of using a database
* Keep routes and templates simple
* Follow existing Flask patterns in the project

## Things Claude Should Not Do

* Do not add unnecessary dependencies
* Do not add databases or authentication systems
* Do not modify tests just to make them pass
* Do not overcomplicate the project structure
